# Studies

개념을 학습하고 기존 지식과 방법을 검토하는 공간입니다. 학습 목차와 순서는 이 문서에서 관리합니다.

## 학습 영역

### [Foundations](foundations/README.md)

클라우드 비용과 자원 사용의 공통 개념, FinOps 기본 개념, 과금과 관측 지표의 관계, 비용·성능·안정성 비교 기준을 다룹니다. 현재 [클라우드 비용과 자원 효율의 기초](foundations/README.md) 문서가 있습니다.

### [AWS Services](aws/README.md)

AWS 서비스별 작동 원리, 과금 항목과 비용 산정, 자원 구성과 실제 사용량, 낭비 발생 원인, 기존 최적화 방법과 적용 조건을 공부합니다. 필요한 공식 자료와 관련 연구도 함께 기록합니다. 실제 학습이 시작된 서비스부터 하위 폴더를 추가합니다.

### [Methods](methods/README.md)

비용 예측, 비용 이상탐지, 자원 사용량 예측, Rightsizing 및 자원 추천, 구성 최적화, 관련 논문과 모델의 방법론 비교를 다룹니다. 이는 탐색 가능한 연구 영역의 예시이며 필수 구현 목록이나 확정 일정이 아닙니다.

## 학습 순서

1. Foundations에서 공통 개념과 비교 기준을 살펴봅니다.
2. 관심 있는 AWS 서비스를 선택해 과금과 자원 사용의 관계를 공부합니다.
3. 연구 질문에 필요한 Methods를 검토하고, 필요한 경우 계산·재현·실험으로 연결합니다.

현재 Foundations 학습 문서가 있으며 AWS Services와 Methods는 안내 문서만 있습니다. 문서 존재는 학습 완료를 뜻하지 않습니다. 모든 주제에 실험이나 모델 학습을 요구하지 않습니다.

기록은 날짜나 주차보다 주제를 중심으로 묶고, 디렉터리 이름에 chapter-01·chapter-02나 주차 번호를 붙이지 않습니다. 논문과 코드는 관련 주제에서 함께 검토하고, 내용이 커질 때만 별도 파일로 나눕니다.

## 학습 기록

학습 노트에는 필요한 만큼 다음을 남깁니다.

1. 공부하게 된 질문
2. 읽은 자료와 확인한 범위
3. 핵심 개념·계산·기존 방법
4. 원문의 주장과 자신의 해석
5. 직접 확인한 내용
6. 현재 결론과 남은 질문

실험을 수행하면 해당 [experiments](../experiments/README.md) 문서로 연결하고, 같은 결과를 여러 문서에 중복해서 작성하지 않습니다.
