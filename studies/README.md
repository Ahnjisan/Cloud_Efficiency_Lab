# Studies

개념을 학습하고 기존 지식과 방법을 검토하는 공간입니다. 클라우드 비용과 자원 사용의 공통 개념, AWS 서비스별 과금 구조와 비용 계산, 낭비 발생 원인과 판단에 필요한 자료, 기존 해결법을 다룰 수 있습니다. 관련 논문, 공식 도구와 공개 구현도 살펴보고 모델의 입력·가정·평가 방법·적용 한계를 검토합니다.

기록은 날짜나 주차보다 주제를 중심으로 묶습니다. EC2·EBS 등은 앞으로 다룰 수 있는 주제의 예시입니다. 논문과 코드는 관련 주제에서 함께 검토하고, 내용이 커질 때만 별도 파일로 나눕니다.

학습 노트에는 필요한 만큼 다음을 남깁니다.

1. 공부하게 된 질문
2. 읽은 자료와 확인한 범위
3. 핵심 개념·계산·기존 방법
4. 원문의 주장과 자신의 해석
5. 직접 확인한 내용
6. 현재 결론과 남은 질문

실험을 수행하면 해당 [experiments](../experiments/README.md) 문서로 연결하고, 같은 결과를 여러 문서에 중복해서 작성하지 않습니다.
