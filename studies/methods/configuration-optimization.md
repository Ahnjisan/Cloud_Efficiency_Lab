# 구성 최적화 — 목적 함수·제약·탐색 예산

[워크로드 성능](../foundations/workload-performance.md)을 기준으로 후보 중 품질 제약을 만족하는 구성의 비용을 최소화한다.

## 방법과 가상 비교

의사결정 변수는 인스턴스 종류·개수·메모리·병렬도 등이다. 목적은 동일 성공 업무량당 총비용을 최소화하는 것이다. p99·오류율·장애 시 처리량은 제약으로 둔다. 소수 후보는 그리드 탐색으로 조합을 비교한다. 측정이 비싼 경우 베이지안 최적화는 관측값으로 대리 모델을 갱신하고 개선 기대와 불확실성을 함께 고려해 다음 후보를 고른다. 추정 오차와 측정 예산을 기록한다.

가상 A는 $8·p99 240 ms, B는 $10·180 ms, C는 $12·160 ms다. 동일 처리량·오류 요건에 p99 200 ms 제약을 더하면 B가 가장 싼 관측 후보이다. 170 ms면 C만 통과한다. CherryPick 저자들은 클라우드 분석 작업의 구성 탐색에 베이지안 최적화를 사용한다. 적용 대상·비용 모델·측정 잡음이 다르므로 이 저장소의 후보 우위는 별도 검증한다.
