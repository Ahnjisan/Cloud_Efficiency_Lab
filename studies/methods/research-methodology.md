# 연구 방법 — 가설·기준선·재현 범위

질문을 검증 가능한 비교로 바꾼다. 예를 들어 동일한 요청 분포에서 CPU 요청 변경이 p99 한도를 유지하며 비용을 낮추는지를 묻는다. [실험 안내](../../experiments/experiment-guide.md)에서 실행 기록의 범위를 구체화한다.

## 설계와 해석

현재 구성을 기준선으로 두고 한 번에 바꿀 변수, 통제할 버전·부하·리전·캐시 상태, 성공 조건과 중단 규칙을 미리 정한다. 반복 순서를 교차해 시간 효과를 줄이고 평균과 산포, 실패한 반복을 남긴다. 시계열은 순서로 분할하고 테스트 자료로 임계값을 조정하지 않는다. 논문 방법 일부를 작은 예제로 적용하면 축소 재현으로 범위를 기록한다.

가상 paired p99 차이(후보−기준선)가 -5, -3, +2 ms이면 평균 -2 ms, 범위 -5~+2 ms다. 세 반복만으로 일반적 개선을 확정하기 어렵고 운영 한계·측정 잡음과 함께 해석한다. 데이터 출처, 접근 조건, 환경, 버전, 시드, 원본과 집계 규칙을 기록하고 결과 없음·가설 기각·재현 실패도 구분한다.
