# Methods

여러 AWS 서비스에 적용할 수 있는 분석·예측·최적화 방법을 공부하는 공간입니다.

## 학습 범위

- 비용 및 자원 사용량 예측
- 비용 이상탐지
- 자원 적정성 및 추천
- 구성 최적화
- 관련 통계·머신러닝 방법
- 기존 논문과 모델 비교

위 항목은 연구 영역의 예시이며 필수 구현 목록이나 확정 일정이 아닙니다.

## 기록 원칙

각 방법을 공부할 때 필요한 범위에서 다음을 기록합니다.

- 해결하려는 문제와 입력 데이터
- 방법의 핵심 원리와 가정
- 기존 기준선과의 차이
- 평가 지표
- 적용 조건 및 한계
- 관련 학습·실험 문서

기존 논문을 읽는 것과 모델을 직접 재현하는 것을 구분하며, 기존 결과를 자신의 실험 성과처럼 표현하지 않습니다. 실제 코드 실행 및 결과는 [Experiments](../../experiments/README.md)에 기록하고 해당 실험 문서와 연결합니다.

## 방법별 문서 탐색

현재 등록된 방법별 학습 문서는 없습니다. 아직 학습하지 않은 모델이나 논문을 완료 항목으로 등록하지 않습니다. 방법론별 하위 폴더는 미리 만들지 않고 실제 학습 자료가 생길 때 추가합니다.
