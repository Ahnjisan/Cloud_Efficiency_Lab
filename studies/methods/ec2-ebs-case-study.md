# EC2·EBS 가상 연구 사례 — 청구 행에서 축소와 롤백 판단까지

**연구 질문.** 주문 조회 서비스의 EC2 사양을 줄여도 피크 응답시간과 복구 요건을 충족하며 당월 청구액을 낮출 수 있는가?

이 사례의 청구 행, 요율, 운영 기록, 관측값은 모두 가상이다. [AWS 비용 데이터](../aws/cost-data/README.md), [EC2 Rightsizing](../aws/ec2/rightsizing-and-autoscaling.md), [EBS 비용 산정](../aws/ebs/README.md)의 판단 기준을 한 사례에 적용한다.

## 1. 청구 행을 자원과 운영 기록에 연결

30일(720시간), 같은 가상 계정·리전·USD를 기준으로 한다. 아래 표는 원본 내보내기 형식을 간소화한 것이다. 약정 적용 EC2 사용 행의 $0은 AWS CUR의 약정 적용 사용 행(`SavingsPlanCoveredUsage`)에 표시되는 On-Demand 상당액과 그에 대응하는 상계 행(`SavingsPlanNegation`)을 합친 순액이다. 정기 약정료는 별도 행에 표시한다. [AWS CUR의 Savings Plans 행](https://docs.aws.amazon.com/cur/latest/userguide/cur-sp.html) 세금·크레딧·전송·관측·스냅샷 비용과 테스트 중 중복 실행 비용은 비교 범위에서 제외한다.

| 가상 청구 항목 | 자원 또는 약정 키 | 과금 수량 | 변경 전 청구액 |
|---|---|---:|---:|
| Compute Savings Plans 정기 약정료 | `sp-orders` | 720시간 × $0.12/시간 | $86.40 |
| 약정으로 전액 커버된 EC2 컴퓨팅 | `i-orders` | 720 인스턴스·시간 | $0.00 |
| 서비스에 연결된 gp3 | `vol-data` | 100 GiB·월 × $0.08/(GiB·월) | $8.00 |
| 미연결 복구용 gp3 | `vol-recovery` | 50 GiB·월 × $0.08/(GiB·월) | $4.00 |
| 용도를 확인하지 못한 미연결 gp3 | `vol-unknown` | 25 GiB·월 × $0.08/(GiB·월) | $2.00 |
| 합계 | | | **$100.40** |

계정·리전·리소스 ID와 시간 구간을 맞춰 비용 행을 자원 인벤토리, 모니터링, 변경·복구 기록과 연결한다. 약정 행은 인스턴스 ID 대신 약정 식별자와 같은 시간대의 적용 사용량으로 확인한다. ID나 이력이 누락되면 비용은 집계하되 소유권이나 사용 여부를 추정해 채우지 않는다.

| 대상 | 확인한 가상 근거 | 판단 |
|---|---|---|
| `i-orders` | 주문 서비스 소유. 최근 30일에 일간 피크를 포함해 CPU p95가 4 vCPU의 35%(1.4 vCPU 상당), 최대 1.8 vCPU 상당, 메모리 최대 3.2 GiB. 기준 구성은 4 vCPU·8 GiB | **축소 후보.** 2 vCPU·4 GiB를 시험할 근거는 있다. 관측 피크만으로도 CPU 90%, 메모리 80%에 해당하므로 피크 지연과 여유 용량이 통과 조건이다. |
| `vol-data` | 현재 서비스의 데이터 볼륨. 앱의 읽기·쓰기 기록과 연결 이력이 일치 | **유지.** EC2 크기만 비교하도록 볼륨 구성은 고정한다. |
| `vol-recovery` | 최근 I/O 없음. 운영팀 복구 계획에 이 볼륨의 보존 기한과 사용 절차가 명시됨 | **유지.** 미연결 상태는 복구 대기 목적과 일치한다. 기한 만료나 대체 복구 경로를 확인한 뒤 별도로 재평가한다. |
| `vol-unknown` | 소유 태그 없음. 이관 종료 기록과 복구 의존성을 확인하지 못함 | **판단 보류.** 월 $2는 보이는 비용이다. 소유자·연결 이력·복구 의존성 확인 전에는 삭제나 절감액에 포함하지 않는다. |

## 2. 정가 차이와 약정 반영 후 청구액

가상의 기존 Compute Savings Plans는 **선결제 없음, $0.12/시간 약정**이며 두 구성 모두 적용 대상이다. 매시간 인스턴스 한 대가 실행되고, 같은 약정을 소비할 다른 적격 사용은 없다. AWS의 약정은 시간 단위로 적용되므로 미사용 금액을 다른 시간으로 이월하지 않는다. 아래는 이 조건이 720시간 동일하게 이어진다고 가정한 월 환산이다.

| 비교 항목 | 기준 4 vCPU·8 GiB | 후보 2 vCPU·4 GiB |
|---|---:|---:|
| 가상 On-Demand 컴퓨팅 요율 | $0.20/시간 | $0.10/시간 |
| 약정이 없다고 가정한 컴퓨팅 | $0.20 × 720 = $144.00 | $0.10 × 720 = $72.00 |
| 가상 Savings Plans 적용 요율 | $0.12/시간 | $0.06/시간 |
| 약정 소비분 | $86.40 | $43.20 |
| 미사용 약정분 | $0.00 | $43.20 |
| 약정료와 초과 On-Demand 컴퓨팅의 합 | $86.40 + $0.00 = $86.40 | $86.40 + $0.00 = $86.40 |
| EBS 3개 합계 | $14.00 | $14.00 |
| **모델 범위의 약정 반영 후 월 청구액** | **$100.40** | **$100.40** |

On-Demand 요율로 비교한 차이는 월 **$72.00**이다. 이 약정이 유지되는 조건에서는 소비가 줄어든 **$43.20**만큼 미사용 약정이 늘고, 모델상 당월 청구액 차이는 **$0.00**이다. 소비분과 미사용분은 동일한 $86.40 약정료의 구성이다. 다른 적격 사용에 약정이 적용돼 그 사용의 On-Demand 비용을 피할 수 있다면 계정 전체를 같은 시간 단위로 다시 계산한다.

## 3. 가상 피크 비교와 롤백 판단

가설은 후보가 기존 서비스 품질을 유지하면서 비용을 줄인다는 것이다. 비교 전에 **피크 p99 ≤ 200 ms, 오류율 ≤ 0.5%**를 통과 기준으로 둔다. 기준과 후보에 같은 요청 구성과 입력률 100건/초를 적용하고, 앱 버전·EBS 구성·워밍업 조건을 맞춘 15분 구간을 비교한다. 구간당 입력은 90,000건이며 p99는 성공 응답 기준, 오류율은 전체 요청 기준으로 본다. 비교 가능한 피크 구간에서 p99가 2회 연속 기준을 넘으면 후보 트래픽을 중단하고 기준 구성으로 되돌리는 규칙을 미리 정한다.

| 가상 관측 | 기준 구성 | 후보 구성 |
|---|---:|---:|
| 피크 1구간 p99 | 172 ms | 232 ms |
| 피크 2구간 p99 | 178 ms | 245 ms |
| 피크 오류율(구간 1 / 2) | 0.2% / 0.2% | 0.3% / 0.4% |

오류율은 두 구성 모두 통과하지만, 후보의 피크 p99가 두 구간 모두 한도를 초과하므로 **롤백 조건에 해당한다**. 가상 절차는 후보 트래픽을 중단하고 기준 구성을 복원한 뒤, 같은 입력 조건에서 p99·오류율 회복과 데이터 볼륨 연결 상태를 확인하는 것이다. 회복 수치는 관측했다고 가정하지 않는다. 원인 분석에는 CPU 실행 대기, 메모리 압력, EBS 지연, 요청 구성 차이를 대조한다. 이 표만으로 병목 원인을 확정할 수 없다.

## 4. 피크 품질을 통과한 후보의 두 청구 시나리오

앞 절의 2 vCPU·4 GiB 후보와 별도로, 메모리 여유를 남긴 **2 vCPU·8 GiB 후보**를 가정한다. 같은 요청 구성과 입력률로 비교한 가상 피크 p99는 188 ms와 195 ms, 오류율은 각각 0.3%와 0.4%다. 두 구간 모두 앞서 정한 p99 200 ms 이하와 오류율 0.5% 이하를 충족한다. 이 결과만으로 앞선 후보의 지연 원인이 메모리였다고 단정할 수 없으며, 운영 피크와 장애 시 여유는 별도로 검증한다.

이 후보의 가상 On-Demand 요율은 $0.15/시간, Savings Plans 요율은 $0.09/시간이다. 기준 구성의 On-Demand $0.20/시간과 비교한 차이는 720시간 × $0.05/시간 = **월 $36.00**이다. 아래 두 시나리오 모두 기존 약정(선결제 없음) $0.12/시간과 EBS 월 $14.00을 유지한다.

- **시나리오 A · 다른 적격 사용이 없음.** 기준 구성은 약정 $0.12/시간을 모두 소비한다. 후보는 $0.09/시간을 소비하고 나머지 $0.03/시간은 미사용이다.
- **시나리오 B · 같은 시간에 다른 적격 사용이 있음.** 같은 계정의 기존 보조 EC2 작업이 기준과 후보 모두에서 매시간 동일하게 실행된다. 이 작업의 가상 요율은 On-Demand $0.04/시간, Savings Plans $0.03/시간이다. 다른 약정이나 RI가 없다고 가정한다. 주문 서비스의 가상 할인율은 두 구성 모두 40%이고 보조 작업은 25%이므로, AWS 적용 순서에 따라 주문 서비스가 먼저 약정을 소비한다. 기준 구성에서는 보조 작업이 On-Demand로 청구된다. 후보에서는 매시간 남는 $0.03이 보조 작업의 약정 요율을 전액 커버한다. [AWS Savings Plans 적용 순서](https://docs.aws.amazon.com/savingsplans/latest/userguide/sp-applying.html)

| 월 720시간 기준 | A · 기준 | A · 후보 | B · 기준 | B · 후보 |
|---|---:|---:|---:|---:|
| 고정 약정료 ($0.12 × 720) | $86.40 | $86.40 | $86.40 | $86.40 |
| 주문 서비스에 적용된 약정 금액 | $86.40 | $64.80 | $86.40 | $64.80 |
| 보조 작업에 적용된 약정 금액 | $0.00 | $0.00 | $0.00 | $21.60 |
| 미사용 약정 금액 | $0.00 | $21.60 | $0.00 | $0.00 |
| 보조 작업의 별도 On-Demand 비용 | $0.00 | $0.00 | $0.04 × 720 = $28.80 | $0.00 |
| 주문 서비스 EBS 합계 | $14.00 | $14.00 | $14.00 | $14.00 |
| **모델 범위의 월 청구액** | **$100.40** | **$100.40** | **$129.20** | **$100.40** |

약정 적용액과 미사용액은 고정 약정료의 구성이다. 청구액 합계에는 고정 약정료, 별도 On-Demand 비용, EBS만 더한다. A에서 월 청구액 차이는 **$0.00**이다. B에서 월 청구액 차이는 **$28.80**이며, 후보가 비운 약정 금액 $21.60을 보조 작업에 적용해 피한 On-Demand 비용이다. 각 시나리오 안에서 동일한 업무량을 비교한다. 보조 작업이 있는 B의 기준과 없는 A의 기준은 업무 범위가 다르다. 보조 작업이 후보와 같은 시간에 360시간만 실행된다면 가정상 피하는 요금은 $0.04 × 360 = $14.40이다. 나머지 시간의 미사용 약정을 옮겨 적용할 수 없다.

### 채택 기준 비교

| 판단 기준 | A · 청구액 동일 | B · 청구액 감소 |
|---|---|---|
| 피크 품질 | 두 가상 구간에서 통과 | 같은 후보와 부하 가정에서 통과 |
| 비용 목적의 채택 | **보류.** 약정이 유지되는 기간의 청구 절감 근거가 없다. | **조건부 채택 후보.** 같은 시간대에 보조 작업이 약정을 소비하는지 확인하고, 전환·중복 실행 및 추가 운영비를 반영한 순절감이 목표 기간에 양수인지 검증한다. |
| 운영 적용 후 확인 | 추가 피크와 장애 조건을 확인한다. | 같은 품질 검증에 더해 시간별 약정 적용액과 보조 작업의 On-Demand 청구 행을 대사한다. |

품질 통과는 두 가상 피크 구간에 한정된다. 실제 적용을 검토할 때는 대표 피크, 오류율, 장애 시 여유를 확인하고 앞 절의 p99 롤백 기준을 유지한다. 보조 작업이 주문 서비스와 자원을 공유해 부하를 바꾸는 환경이라면 B의 품질 결과도 별도로 확인한다.

## 결론과 확인 질문

[EC2 용량 결정 기록](ec2-capacity-decision.md)에서 현행 유지, 사양 축소, 피크 시간대 확장 대안을 비교한다.

첫 후보는 피크 p99 기준을 초과해 롤백 대상이다. 피크를 통과한 두 번째 후보는 다른 적격 사용이 없으면 비용 목적의 채택을 보류하고, 같은 시간의 보조 작업에 약정이 적용되면 조건부 채택 후보가 된다. 데이터·복구 EBS는 유지하고 소유 미확인 EBS는 판단을 보류한다. 실제 청구 행이나 운영 성능으로 검증한 결과는 없다. 후속 검증 조건은 [실험 안내](../../experiments/experiment-guide.md)에 따른다.

- 다음 달에 약정 조건이 바뀌거나 다른 적격 사용이 늘면 어느 비용 행을 다시 대사해야 하는가?
- 미연결 볼륨의 소유자만 확인되고 복구 의존성이 확인되지 않았다면 판정이 달라지는가?
