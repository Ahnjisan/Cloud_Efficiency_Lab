# EBS 낭비 권고 — 팀 검토와 사후 확인 흐름

**목적.** [가상 탐지 평가](ec2-ebs-waste-detection-evaluation.md)의 규칙 B를 공통 검토 절차로 사용한다. 경보는 검토를 시작하는 근거다. 이 문서는 팀의 역할과 기록 방식을 설계한 가상 사례다.

## 1. 접수와 판정

권고 기록 한 건의 범위는 **계정·리전·볼륨 ID·관측 시점**이다. 비용 기간과 청구 행의 출처, 월 비용과 회피 가능액의 가정, 연결 상태·마지막 연결 이력, 소유팀, 사용 종료·보존·복구 근거의 출처와 확인일, 규칙 버전을 함께 남긴다. 같은 볼륨에 후속 근거가 오면 기존 기록에 이력으로 추가한다. 권고 출력에는 판정, 이유, 다음 담당자, 재검토 기한을 남긴다.

| 판정 순서 | 권고 출력 | 처리 |
|---|---|---|
| 연결된 볼륨 | 범위 밖 · 경보 없음 | 정상 확인으로 기록하지 않는다. 별도 조사에서 중복이 의심되면 소유팀에 의뢰한다. |
| 미연결이며 판단에 필요한 기록이 누락되거나 충돌 | 보류 | 빈 항목이나 충돌 근거를 명시하고 소유팀 또는 자원 인벤토리 담당자에게 확인을 요청한다. 기한이 지나면 플랫폼 담당자가 재배정하며 보류 상태를 유지한다. |
| 미연결이며 유효한 운영·복구 목적 확인 | 유지 · 경보 없음 | 확인한 목적과 보존 종료일 또는 다음 검토일을 기록한다. |
| 미연결이며 소유자·사용 종료·보존 및 복구 의존성 없음이 모두 확인됨 | 경보 · 검토 요청 | 소유팀에 변경 가능 여부와 회피 가능 비용의 근거를 확인받는다. |
| 위 근거로 판정 불가 | 보류 | 부족한 근거를 남기고 재검토한다. |

## 2. 검토, 승인, 사후 확인

1. **플랫폼 담당자**가 입력과 판정 근거를 정리하고 소유팀에 전달한다. 소유팀을 찾지 못하면 인벤토리 담당자에게 연결한다.
2. **워크로드 소유팀**이 실제 용도와 서비스 의존성을 확인한다. **백업·복구 담당자**는 필요한 보존 기간, 데이터 복구 가능 여부, 대체 경로를 확인한다. 근거가 충돌하거나 변경 직전에 연결 상태가 달라지면 보류로 되돌린다.
3. **변경 승인자**는 적용 대상과 범위, 변경 시간, 영향, 복구 경로와 사후 기준을 기록한 뒤 승인 여부를 결정한다. 복구가 필요한 경우 별도 복구본과 복원 가능성을 먼저 확인한다. 삭제의 복구 가능성을 가정하지 않는다.
4. **실행 담당자**는 승인된 범위의 작업 결과를 남긴다. **소유팀과 비용 담당자**는 서비스·복구 상태를 확인하고, 청구 데이터가 반영된 뒤 자원 비용과 추가 스냅샷 등으로 옮겨간 비용을 대사한다. 품질 문제가 생기면 추가 작업을 중단하고 승인된 복구 경로를 검토한다. 청구 또는 품질 근거가 부족하면 검증 대기로 남긴다.

## 3. 가상 입력을 따라가 보기

| 볼륨 | 첫 판정 | 다음 처리 |
|---|---|---|
| `vol-migrated` | 경보 | 주문팀은 이관 완료와 서비스 의존성 해소의 근거를 확인하고, 복구 담당자는 보존 의무와 복구 의존성이 해소됐다는 근거를 확인한다. 변경 승인자는 확인 결과를 검토해 승인 여부를 결정한다. 승인·실행·청구 대사 결과는 아직 없다. |
| `vol-recovery` | 유지 | 복구 계획과 보존 종료일을 기록한다. 기한이 끝나도 대체 경로를 확인한 뒤 다시 판정한다. |
| `vol-transfer` | 보류 | 이관팀과 복구 담당자가 서로 다른 기록의 유효 시점과 근거를 대조한다. 해소 전에는 정상이나 절감액으로 집계하지 않는다. |
| `vol-stale` | 범위 밖 | 연결된 볼륨이라 규칙은 놓쳤다. 별도 조사에서 의존성이 해소됐다는 증거를 받으면 수동 검토로 접수한다. |

가상 8건에 처음 적용하면 규칙 A의 경보 5건에 비해 규칙 B는 경보 2건과 보류 2건을 만든다. 경보와 보류를 모두 사람이 확인하는 조건에서는 **초기 검토 대기 건수가 5건에서 4건으로** 줄어든다. 유지·범위 밖 건의 정기 점검, 경보와 보류 각각의 조사 시간은 이 계산에서 제외했다. 실제 운영 평가에서는 오탐·미탐, 보류 건수와 체류 시간, 담당자 확인 시간, 승인 후 대사한 순절감을 따로 본다. 확인되지 않은 건과 실행 전 권고액은 절감 실적으로 집계하지 않는다.
