# AWS Services

## 학습 목적

AWS 서비스별 과금 구조와 실제 자원 사용의 관계를 이해하고 비용 낭비의 발생 조건, 판단 근거, 기존 해결 방법을 공부합니다.

## 서비스별 학습 내용

학습할 때 다음 관점을 필요한 범위에서 참고합니다. 모든 학습 노트에 동일한 목차를 강제하지 않습니다.

1. 서비스의 역할과 작동 원리
2. 과금 구조와 비용 산정 기준
3. 설정·사용량·성능의 관계
4. 낭비 발생 원인
5. 기존 해결 방법과 적용 조건
6. 판단에 필요한 자료와 확인하지 못한 부분
7. 관련 공식 자료·논문·연구 질문

## 서비스별 문서 탐색

현재 등록된 서비스별 학습 문서는 없습니다. 새로운 서비스 학습을 시작할 때 해당 폴더를 만들고, 실제 작성한 문서의 상대 링크를 이 목차에 추가합니다.
