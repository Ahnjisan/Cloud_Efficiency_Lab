# References

외부 자료의 위치와 참고 목적을 안내하는 공간입니다. AWS 공식 문서를 비롯한 공식 자료, 학술 논문, 공식 데이터셋, 원저자 코드와 보조 자료를 구분해 기록합니다.

자료별로 필요한 범위에서 제목과 저자·기관, 원문 링크, 발행·개정 시점 또는 확인한 버전·커밋, 읽거나 검토한 범위와 확인일, 참고한 이유를 남깁니다. 코드·데이터 등을 재사용하면 라이선스와 수정 범위도 기록합니다.

외부 자료의 코드·데이터를 구체적으로 재사용할 때는 해당 자료의 라이선스와 재배포 조건을 별도로 확인합니다. 외부 자료에 이 저장소의 LICENSE가 자동으로 적용되지는 않습니다.
