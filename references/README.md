# References

공식 자료 및 학술 참고문헌의 위치와 참고 목적을 안내하는 공간입니다.

## 포함할 자료

- AWS 공식 기술·요금·API 문서
- 클라우드 공급자의 공식 문서
- FinOps Foundation의 공식 자료
- FOCUS 등 공식 표준·사양
- 정식 학술 논문과 별도로 구분한 프리프린트
- 공식 공개 데이터셋

## 참고문헌 관리

자료별로 필요한 범위에서 다음을 기록합니다.

- 제목과 저자 또는 발행 기관
- 발행·개정 시점과 확인한 버전
- 원문 URL
- 실제 읽은 절 또는 페이지와 확인일
- 관련 학습 주제와 참고 목적

초기에는 이 README의 단일 목록으로 관리합니다. 자료가 많아졌을 때만 `official-docs.md`, `standards.md`, `papers.md`, `datasets.md` 등으로 분리를 검토합니다.

## 참고문헌 목록

기존 Foundations 문서에 기록된 공식 자료와 확인 범위는 [확인한 자료와 해석 범위](../studies/foundations/README.md#확인한-자료와-해석-범위)에서 찾을 수 있습니다. 이번 구조 정리에서는 새 문헌을 조사하거나 추가하지 않았습니다. 목록에 등록했다는 사실만으로 자료를 읽었거나 학습을 완료했다고 표시하지 않습니다.

## 외부 자료 재사용

공식 참고문헌 목록에는 다른 개인의 GitHub 프로젝트나 동아리 스터디 저장소를 등록하지 않습니다. 기존에 참고 대상으로 나열했던 개인 프로젝트의 코드·데이터는 재사용하지 않았습니다.

외부 코드·데이터·독창적인 분석 방법을 실제로 재사용하면 해당 [Studies](../studies/README.md) 또는 [Experiments](../experiments/README.md) 문서에 원 출처, 확인한 버전·커밋, 라이선스, 수정 범위를 기록합니다. 라이선스와 재배포 조건을 별도로 확인하며, 외부 자료에 이 저장소의 LICENSE가 자동으로 적용되지는 않습니다.
