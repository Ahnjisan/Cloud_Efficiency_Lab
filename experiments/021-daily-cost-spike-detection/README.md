# 021 — 일별 비용 급증 탐지 규칙의 오탐·미탐·지연

[실험 목차](../README.md) · [최종 연구 보고서](../../FINAL-REPORT.md) · [이상탐지 학습 노트](../../studies/methods/anomaly-detection.md)

**합성 평가 재현 PASS. H1 기각(경보일 제외 설정에서만 성립), H2 기각.** 정상 추세·주말 하락·점진 증가·급증이 섞인 합성 일별 비용 시계열에서 단순 규칙 3개를 비교했다. 임계값은 조정용 시계열에서만 고르고, 별도 평가용 시계열에서 성능을 측정했다. 비용 금액은 가상 값이며 AWS 요율과 무관하다.

## 실행 전 결정

| 항목 | 내용 |
|---|---|
| 질문 | 일별 비용 급증을 조기에 알리는 단순 규칙은 오탐·미탐·탐지 지연 면에서 어느 정도 쓸 만한가? |
| 가설 H1 | 같은 요일 기준선 규칙(R3)은 14일 평균+kσ 규칙(R1)보다 오탐이 적거나 같고, 급증 재현율은 5%p 이상 낮지 않다. 경보일 제외 여부 두 설정 모두에서 성립해야 지지한다. |
| 가설 H2 | 세 규칙 모두 점진 증가 사건의 재현율이 20% 미만이다. 하나라도 20% 이상이면 기각한다. |
| 규칙 | R1: 최근 14일 평균 + kσ (k ∈ {2, 2.5, 3, 3.5, 4}). R2: 최근 28일 중앙값 + k × 1.4826 × MAD, 그리고 중앙값보다 10% 이상 (k ∈ {3, 4, 5, 6, 8}). R3: 최근 4주 같은 요일 중앙값 × (1 + r), 그리고 10% 이상 (r ∈ {0.2, 0.3, 0.5, 0.75, 1.0}). 각 규칙에 경보일을 기준선에서 빼는 변형을 더함 |
| 선택 규칙 (사전 결정) | 조정용 시계열에서 오탐 30 정상일당 1.0건 이하인 파라미터 중 급증 재현율 최대, 동률이면 오탐이 적은 쪽 |
| 데이터 | 합성. 시계열마다 기본 수준 10~50, 연 0~15% 추세, 주말 배수 0.6~0.8, 곱셈 잡음 σ 0.05~0.12. 급증 4~8회(1~3일, +50%~+300%), 점진 증가 1~2회(21~42일에 걸쳐 +40%~+80%로 오른 뒤 유지) |
| 시드·분할 | 조정용 시드 1~20, 평가용 시드 101~120. 시계열마다 준비 기간 56일 + 평가 365일 |
| 지표 | 사건 단위 재현율(사건 기간 중 하루라도 경보면 탐지), 정상일 30일당 오탐, 급증 시작일부터 첫 경보까지 지연(일) |

점진 증가는 오르는 구간만 사건으로 표시했다. 다 오른 뒤의 새 수준은 정상으로 보고, 그 기간의 경보는 오탐으로 센다.

## 결과 (평가용 시계열 20개: 급증 90건, 점진 증가 34건)

| 규칙 · 경보일 제외 | 선택 파라미터 | 급증 재현율 | 오탐 / 30 정상일 | 점진 증가 재현율 | 평균 지연 |
|---|---:|---:|---:|---:|---:|
| R1 평균+kσ · 유지 | k=2.0 | 96.7% | 0.42 | 94.1% | 0.01일 |
| R1 평균+kσ · 제외 | k=3.0 | 98.9% | 0.045 | 23.5% | 0.02일 |
| R2 중앙값+MAD · 유지 | k=3.0 | 97.8% | **0.040** | 44.1% | 0.04일 |
| R2 중앙값+MAD · 제외 | k=3.0 | 97.8% | 0.50 | 44.1% | 0.04일 |
| R3 같은 요일 · 유지 | r=0.3 | 100% | 0.76 | 100% | 0일 |
| R3 같은 요일 · 제외 | r=0.75 | 98.9% | **0.025** | 11.8% | 0.03일 |

- **H1 기각**: 경보일을 제외하는 설정에서는 R3가 R1보다 오탐이 적었다(0.025 대 0.045, 재현율 동일). 그러나 유지 설정에서는 선택 규칙이 R3의 r=0.3을 골랐고, 평가에서 오탐이 0.76으로 R1(0.42)보다 많았다. 조정용에서 0.58이던 오탐이 평가용에서 0.76으로 늘어, 오탐 예산 1.0에 가까운 파라미터는 다른 시계열에서 예산을 넘기 쉽다는 점도 확인했다.
- **H2 기각**: 점진 증가 재현율이 20%를 넘는 설정이 4개였다(R1 유지 94%, R3 유지 100%, R2 44%). 다만 높은 재현율은 오탐이 많은 민감한 파라미터에서 나왔다. 오탐이 가장 적은 두 설정(R2 유지, R3 제외)의 점진 증가 재현율은 44%와 12%였다.
- **주말 관련 오탐**: R1 유지 설정의 오탐 85건은 모두 평일(월 21, 화 16, 수 22, 목 16, 금 10)이었고 주말은 0건이었다. 14일 창에 주말 4일이 섞여 평균이 내려가므로 평일 전체가 기준선 위에 놓인다. 예상했던 "월요일 집중"은 나타나지 않았다.
- **경보일 제외의 폭주**: R2를 같은 파라미터(k=3)로 비교하면 경보일을 제외할 때 오탐이 0.040에서 **0.50**으로 늘었다. 점진 증가 뒤의 새 수준이 계속 경보로 잡히고, 그 날들이 기준선에서 빠지면서 기준선이 옛 수준에 고정된다. 영구적인 수준 이동 40일에 대해 제외 설정은 40일 모두 경보를 냈다(테스트로 고정).
- **지연**: 탐지된 급증의 대부분은 시작 당일에 잡혔다(R3 제외: 0일 86건, 1일 3건). 실제 운영에서는 청구 데이터 지연(Cost Explorer 기준 최대 24시간)이 더해진다.

## 해석

- 급증 크기가 +50% 이상이고 잡음이 σ 0.12 이하인 이 합성 조건에서는 세 규칙 모두 급증을 97% 이상 잡았다. 규칙 간 차이는 주로 **오탐과 점진 증가에 대한 반응**에서 났다.
- "경보일을 기준선에서 뺀다"는 설정은 급증이 길어질 때 기준선 오염을 막지만, 정상적인 수준 이동이 있으면 경보가 멈추지 않는다. 운영 규칙에는 제외 기간 상한(예: 연속 N일 경보 후 기준선 재설정)이나 사람이 수준 이동을 승인하는 절차가 필요하다. 이 상한값은 이번에 검증하지 않았다.
- 점진 증가는 급증 규칙의 부산물로 잡히는 경우가 있지만, 잡히는지는 파라미터에 크게 좌우된다. 별도의 추세 규칙으로 다루는 편이 낫다.

## 가정·제외·한계

- 급증 크기 하한이 +50%다. +10%~+30% 수준의 작은 급증은 평가하지 않았다. 원하는 결론에 맞추지 않기 위해 결과를 본 뒤 생성 조건을 바꾸지 않았으며, 작은 급증은 다음 질문으로 남겼고, [024](../024-cost-spike-rule-fixes/README.md)에서 같은 생성기로 급증 크기만 +10~30%로 바꿔 평가했다(재현율 21.5%).
- 휴일, 월초 일괄 청구(약정료·지원료 등), 환율·할인 변경, 청구 정정은 생성하지 않았다.
- 시계열마다 서비스 1개다. 여러 서비스가 합쳐진 계정 합계는 작은 서비스의 급증을 가린다.
- AWS Cost Anomaly Detection과 직접 비교하지 않았다(내부 모형 비공개).
