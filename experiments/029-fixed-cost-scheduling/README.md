- **H1 지지**: Classic 구성에서 일정 적용 절감률은 13.3%였다.
- **H2 지지**: 삭제만 가능한 자원이 월 478.22 USD로 상시 비용 607.23 USD의 79%였다. 그중 OpenSearch Classic 최소 OCU가 427.78 USD다.
- **H3 지지**: 한 번 중지하고 잊으면 RDS 절감 52.02 USD 중 17.14 USD(33%)만 남았다.
- 벡터 저장소를 NextGen(0으로 축소)으로 바꾸는 **설계 변경**이 일정 자동화보다 효과가 컸다(절감률 13% → 63%).

## 해석

- 일정 기반 중지 규칙은 "중지할 수 있는 자원"만 다룬다. 고정비 목록을 만들 때 자원마다 **중지 방식(중지/축소/삭제만/중지해도 과금)** 을 먼저 붙여야 절감 추정이 과장되지 않는다.
- RDS 중지는 7일 제한 때문에 "중지 상태"라는 스냅샷만 보고 절감을 계산하면 틀린다. 판단 자료는 상태 변경 이벤트(자동 시작 포함)와 일정 자동화의 존재다.
- InfraFit 규칙 후보: "개발 태그 + 삭제만 가능한 상시 자원(OpenSearch Classic 컬렉션·관리형 도메인, NAT)" → 변경 검토 후보, 근거 수준 공식 자료. 다만 사용 시간대 자료가 없으면 금액은 판단 보류.

## 가정·제외·한계

- NextGen은 사용 시간(220시간) 동안 2 OCU를 쓴다고 가정했다. 10분 비활성 후 축소되므로 실제로는 사용 구간마다 최대 10분이 더해진다. NextGen 요율은 미확인이다.
- 시작·중지에 걸리는 시간, 시작 실패, 데이터 재색인 비용은 넣지 않았다.
- 요청량에 비례하는 비용(모델 토큰, API Gateway 등)은 고정비가 아니라서 이 실험에서 뺐다.
