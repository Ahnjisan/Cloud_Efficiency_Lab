# 002 평가 기준

연구 질문은 연결 여부 기반 규칙 A와 소유·복구 근거 기반 규칙 B가 신규 반례에서 어떤 차이를 보이는가이다. 가설은 B가 유효한 보존 의무의 오탐을 줄이지만, 연결된 불필요 볼륨과 잘못 확인된 근거에는 한계가 있다는 것이다.

두 규칙은 [001](../001-ebs-waste-rules/README.md)의 구현을 변경 없이 호출한다. 유효성을 확인하지 못한 오래된 기록은 입력에서 `missing`으로 표시한다. 이는 사람이 구조화한 입력 조건이며, 규칙이 기록 날짜를 직접 해석하는 것은 아니다. 평가 정답은 입력 시점에 규칙이 볼 수 없는 별도 가상 사후 조사로 정한다. 결과가 불명확하면 미확정으로 둔다.

확정 정답에서 경보·비경보를 TP/FP/FN/TN으로 분류한다. 보류는 확정 낭비/정상과 미확정을 구분해 별도 집계한다. 확정 낭비 보류는 즉시 탐지 재현율 분모에 들어간다. 정밀도는 확정된 경보만, 전체 보류율과 초기 대기 건수(경보+보류)는 전체 입력을 기준으로 계산한다. 분모가 없으면 미정으로 기록한다. 이 목적 표본의 비율을 운영 정확도로 일반화하지 않는다.
