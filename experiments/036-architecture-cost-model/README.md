# 036 — 설계 단계 아키텍처 비용 모델 (원형)

[실험 목차](../README.md) · [기준 시나리오와 공통 모듈](../scenarios/README.md) · [누수 패턴 방법 노트](../../studies/methods/cost-leak-patterns.md) · [019 파이프라인 단가](../019-pipeline-unit-cost/README.md)

**재현 PASS. H1·H2 지지.** 아키텍처를 구성 요소 목록으로 적고, 구성 요소마다 "청구될 금액(올림·최소치·상시 시간 포함)"과 "사용량 기반 금액(요율 × 실제 사용량)"을 함께 계산하는 비용 모델을 만들었다. 019의 1,000건당 비용을 이 모델로 다시 계산해 같은 값이 나오는지 확인하고, 두 기준 시나리오에 적용했다.

## 실행 전 결정

| 항목 | 내용 |
|---|---|
| 질문 | 서비스별 계산을 하나의 모델(구성 요소 × 구동량 × 서비스 팩 × 요율 사본)로 묶어도 기존 실험 결과를 재현하는가? 시나리오에서 검토가 필요한 구성 요소를 자동으로 표시할 수 있는가? |
| 가설 H1 | 모델은 019의 측정값 1,000건당 비용 8개(기준·개선 × 질의 배수 4개)를 소수 6자리까지 같게 재현한다. |
| 가설 H2 | 두 시나리오 모두 검토 표시가 붙은 구성 요소가 월 비용의 50% 이상이다. |
| 모델 | [model.py](model.py): 구성 요소 함수가 `billed`(청구), `usage`(요율 × 실제 사용량, 알 수 없으면 없음), `fixed`(시간 과금 상시 자원)를 돌려준다 |
| 검토 표시 | `minimum_or_rounding_ge_50pct`: (청구 − 사용량 기반) / 청구 ≥ 50% (패턴 1·7). `always_on`: 상시 시간 과금 (패턴 2). `usage_unknown`: 사용량 기반 금액을 알 수 없음(판단 보류) |
| 019 재현 | 구동량(게시 메시지 수, 레코드 수·크기, S3 객체 수, 저장 GB, 크롤러 DPU-시간, 질의별 스캔 바이트)은 016·017·019 결과에서 읽고, 요율은 [2026-11-15 사본](../../references/aws-price-list-apn2-2026-11-15.json)에서 읽는다. IoT·Firehose·S3·Athena·Glue 요율은 2026-11-13 사본과 같다(확인함) |
| 시나리오 | [iot-pipeline-agent.json](../scenarios/iot-pipeline-agent.json), [web-llm-chatbot.json](../scenarios/web-llm-chatbot.json) |

- **H1 지지**: 8개 값 모두 019와 같았다. 019의 구성 요소별 계산을 공통 모델(서비스 팩 + 요율 사본)로 옮겨도 결과가 바뀌지 않는다.
- **H2 지지**: 검토 표시 비중은 ① 57.2%, ② 68.3%였다. 단 이 비중의 대부분은 `always_on`(상시 시간 과금)이며, **검토 표시는 낭비 판정이 아니라 판단 자료가 필요한 후보**다.

## 해석

- InfraFit의 설계 단계 비용 모델은 이 구조(구성 요소 함수 → 청구·사용량·상시 여부 → 패턴 표시)로 시작할 수 있다. 요율은 날짜 붙은 사본에서만 읽고, 사본에 없는 요율(SQS 요청, KB 저장, 인터넷 전송)은 구성 요소를 **제외 목록**에 남긴다.
- 사용량 기반 금액과 청구 금액을 함께 내면 패턴 1(올림)과 패턴 7(최소치)은 서비스와 무관하게 같은 식으로 표시된다. 패턴 2(상시)는 `fixed` 속성으로 표시된다. 패턴 3·5·8(중복 전송, 보관 기간, 측정 비용)은 구성 요소 사이의 관계나 설정 값이 필요해 이 원형에서는 표시하지 못했다.
- 시나리오 결과의 금액 순위는 이전 실험의 결론과 일치한다: ②의 1위는 벡터 저장소 최소치([030](../030-hidden-minimum-charges/README.md)), ①의 IoT 메시지는 묶음으로 크게 줄일 수 있다([016](../016-iot-message-batching/README.md)·[026](../026-billing-unit-rounding/README.md)).

## 가정·제외·한계

- 시나리오 ① 제외: SQS 요청(사본에 없음), Glue 크롤러, Athena의 S3 GET. 시나리오 ② 제외: KB 관리형 저장(사본 `missing`), 인터넷 전송, ALB.
- 첫 달 기준이다. 로그·S3 저장은 보관 기간에 따라 달마다 늘어난다([034](../034-observability-cost/README.md)).
- 무료 제공량, 할인(Savings Plans 등), 세금은 넣지 않았다.
