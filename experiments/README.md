# Experiments

학습 중 직접 확인할 필요가 생긴 내용을 검증하는 공간입니다. 작은 입력을 이용한 비용 계산 검증, 공개·저장 자료를 이용한 분석 방법 비교, 기존 논문·도구·모델의 전체 또는 축소 재현을 할 수 있습니다. AWS 실험은 필요한 경우에만 제한된 범위로 수행합니다.

실험은 질문별로 묶습니다. 각 실험의 README에서 필요한 범위에 따라 다음을 찾을 수 있도록 기록합니다.

- 질문과 가설 또는 확인 목표
- 데이터 출처와 실제·합성 여부
- 실행 환경과 의존성
- 비교 기준선과 변경 조건
- 측정 지표와 실행 방법
- 원본 결과와 집계 방법
- 결과 해석, 한계, 재현 범위

모델 실험에는 필요한 경우 학습·튜닝·평가 자료의 구분과 난수 시드를 남깁니다. 기존 연구와 조건이 다르면 전체 재현이라고 부르지 않고 축소 재현 또는 방법을 참고한 별도 실험으로 구분합니다.

AWS 등 유료 자원을 쓰는 실험은 실행 전에 대상, 예상 비용과 가정, 유지 시간, 중단 조건, 정리 방법을 정하고 사용자 승인을 받습니다. 미측정, 실패, 효과가 없었던 결과도 그대로 기록합니다.
