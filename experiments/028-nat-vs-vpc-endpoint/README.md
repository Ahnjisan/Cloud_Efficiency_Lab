# 028 — NAT 게이트웨이 vs VPC 엔드포인트 손익분기

[실험 목차](../README.md) · [VPC 학습 노트](../../studies/aws/vpc/README.md#추가2026-11-15--nat-게이트웨이-vs-인터페이스게이트웨이-엔드포인트) · [기준 시나리오 ②](../scenarios/web-llm-chatbot.json)

**재현 PASS. H1·H2·H3 지지.** 사설 서브넷에서 AWS 서비스로 가는 트래픽을 NAT로 보낼 때와 VPC 엔드포인트로 보낼 때의 손익분기 트래픽을 일반식으로 구하고, 시나리오 ②(웹 서비스 + 사내 챗봇)의 서비스별 트래픽에 적용했다.

## 실행 전 결정

| 항목 | 내용 |
|---|---|
| 질문 | 서비스별로 인터페이스 엔드포인트가 NAT보다 싸지는 월 트래픽은 얼마이고, 시나리오 ②에서는 무엇을 바꿔야 하는가? |
| 일반식 | 손익분기 GB = 엔드포인트 수 × AZ 수 × 730 × 엔드포인트 시간 요금 ÷ (NAT GB 요금 − 엔드포인트 GB 요금) |
| 가설 H1 | 손익분기보다 트래픽이 적은 서비스는 인터페이스 엔드포인트가 NAT보다 비싸다(식 확인). |
| 가설 H2 | 시나리오 ②에서 가장 큰 단일 절감은 S3 게이트웨이 엔드포인트다. |
| 가설 H3 | 시나리오 ②에서 모든 서비스에 인터페이스 엔드포인트를 두면 NAT만 쓸 때보다 비싸다. |
| 요율 | [2026-11-15 사본](../../references/aws-price-list-apn2-2026-11-15.json): NAT 0.059 USD/시간·0.059 USD/GB(AmazonEC2), 엔드포인트 0.013 USD/시간·AZ, 0.01 USD/GB(AmazonVPC), 게이트웨이 엔드포인트 0 |
| 시나리오 | 2 AZ, NAT 1개. NAT 경유 월 GB: ECR 30, Logs 50, S3 200, Bedrock 런타임 5, 그 밖의 인터넷 20 (가정) |
| 엔드포인트 수 | ECR은 api·dkr 2개, 나머지 1개(가정). ECR 이미지 레이어가 S3에서 내려오는지는 이번에 확인하지 않아 ECR 트래픽 전부를 인터페이스 엔드포인트 몫으로 셈 |

| 구성 | 월 합계 (NAT 고정 43.07 + 인터넷 1.18 포함) |
|---|---:|
| NAT만 | 61.06 USD |
| 모든 서비스에 인터페이스 엔드포인트 | 142.00 USD |
| 서비스별 최저(S3만 게이트웨이) | **49.26 USD** |

- **H1 지지**: ECR·Logs·Bedrock은 손익분기보다 트래픽이 훨씬 작아 NAT가 쌌다. 이 가설은 식이 맞는지 확인하는 성격이다.
- **H2 지지**: 절감은 S3 게이트웨이 엔드포인트(11.80 USD/월)에서만 생겼다.
- **H3 지지**: 인터페이스 엔드포인트를 모두 두면 NAT만 쓸 때의 2.3배다.
- **NAT를 없앨 수 있는 경우**(인터넷 트래픽 0): NAT + S3 게이트웨이 48.08 USD 대 엔드포인트만 76.77 USD(인터페이스 4개 × 2 AZ)로 여전히 NAT 쪽이 쌌다. NAT 삭제가 이득이 되려면 인터페이스 엔드포인트로 옮길 트래픽이 대략 월 571 GB 이상이어야 한다.

## 해석

- "NAT 처리 요금이 비싸니 엔드포인트로"라는 일반 권고는 트래픽이 작은 개발·소규모 환경에서 반대 결과를 낸다. 인터페이스 엔드포인트는 **엔드포인트 × AZ마다** 시간 요금이 붙는 상시 고정비이기 때문이다.
- S3·DynamoDB 게이트웨이 엔드포인트는 고정비가 없어 트래픽과 무관하게 항상 이득이다. InfraFit 규칙 후보: "사설 서브넷 라우팅 표에 S3 게이트웨이 엔드포인트가 없고 NAT가 있다 → 변경 검토 후보(공식 자료)".
- 인터페이스 엔드포인트 규칙은 서비스별 월 GB가 있어야 판정할 수 있다. 흐름 로그가 없으면 판단 보류다.

## 가정·제외·한계

- 서비스별 GB는 가정값이다. 실제로는 VPC 흐름 로그를 목적지 접두사 목록으로 나눠야 한다.
- 보안 요구(인터넷 경로 금지)로 엔드포인트가 필요한 경우는 비용 판단 대상이 아니다.
- AZ 간 전송, 엔드포인트 GB 요금의 리전 합산 구간(1 PB 초과), 부분 시간 올림(생성·삭제 반복)은 넣지 않았다.
