# 034 — 측정 비용: 지표 차원, EMF, 로그 보관

[실험 목차](../README.md) · [CloudWatch 노트](../../studies/aws/cloudwatch/README.md) · [누수 패턴 5·8](../../studies/methods/cost-leak-patterns.md#8-측정-비용)

**재현 PASS. H1·H3 지지, H2 기각.** 비용을 줄이려고 붙인 관측 자체가 비용이 되는 경우를 세 가지로 계산했다: 지표 차원 조합 수, 측정값마다 EMF 로그를 남기는 방식, 로그 보관 기간.

## 실행 전 결정

| 항목 | 내용 |
|---|---|
| 질문 | 지표 차원 설계와 로그 보관 설정은 관측 비용을 얼마나 바꾸는가? |
| 가설 H1 | 사용자 ID처럼 값이 많은 차원을 넣은 지표 설계는 집계 설계보다 10배 이상 비싸다. |
| 가설 H2 | 로그 보관 기간이 무기한이면 12개월 안에 월 저장 요금이 월 수집 요금을 넘는다. |
| 가설 H3 | 디바이스별 지표(차원 DeviceId)의 월 지표 요금이 같은 측정값을 EMF 로그로 남기는 수집 요금보다 크다. |
| 과금 규칙 | 지표 이름 × 차원 값 조합마다 별도 사용자 지정 지표, 데이터를 받은 시간만큼 시간 비례 과금. EMF는 로그 수집·로그 저장·지표 세 가지로 과금. 로그 기본 보관은 무기한 |
| 지표 설계 | A 집계: 지표 3개 + 3개 × DeviceGroup(5). B 디바이스별: 3개 × DeviceId(100). C 고차원: 에이전트 지표 2개 × Tool(10) × Model(2) × User(500), 사용자마다 하루 2시간만 데이터 |
| EMF | 측정값(월 2,592만 건)마다 300 B 이벤트(가정) |
| 로그 | 시나리오 ① 월 20 GB 수집. 저장 GB = 수집 GB로 계산(저장 시 압축 여부 미확인 → 상한) |
| 요율 | [2026-11-15 사본](../../references/aws-price-list-apn2-2026-11-15.json) AmazonCloudWatch(게시일 2026-11-04): 지표 0.30/0.10/0.05/0.02 구간, 로그 수집 0.76 USD/GB, 로그 저장 0.0314 USD/GB-월 |

- **H1 지지**: C는 A의 92.6배였다. 사용자가 하루 2시간만 활동해 시간 비례로 1/12만 과금됐는데도 그렇다.
- **H2 기각**: 무기한 보관에서 월 저장 요금이 월 수집 요금을 넘는 시점은 **25개월째**였다(0.76 / 0.0314 = 24.2). 12개월 시점 월 저장은 수집의 50%다. 다만 36개월 누적 저장은 418 USD로 30일 보관(22.61)의 18.5배다.
- **H3 지지**: 디바이스별 지표 300개(90.00 USD)가 같은 측정값 전체를 EMF 로그로 남기는 수집 요금(5.50 USD)의 16배였다. 지표는 개수로, 로그는 바이트로 과금되기 때문이다.

## 해석

- 관측 비용 규칙의 판단 자료는 **지표 이름별 차원 값 조합 수**다. 사용자·요청·세션 ID 같은 값이 많은 필드는 차원이 아니라 로그 필드(EMF의 속성)로 두고, 필요할 때 Logs Insights로 집계한다.
- 로그 보관은 단기에는 수집 요금이 크고, 무기한 보관의 저장 요금은 2년 넘어서야 수집 요금을 앞지른다. 그러나 누적액은 선형이 아니라 제곱으로 늘어나므로, 보관 기간 미설정 로그 그룹은 **변경 검토 후보**(공식 자료: 기본 무기한)이며 보관 요구(감사·규정)를 모르면 기간은 판단 보류다.
- InfraFit 규칙 후보: (1) 차원 조합 수가 1,000 이상인 지표 이름(실험 확인), (2) 보관 기간이 없는 로그 그룹(공식 자료), (3) 측정값마다 사용자 지정 지표를 내는 디바이스별 차원(실험 확인).

## 가정·제외·한계

- 로그 저장이 압축 후 크기로 과금되면 저장 요금은 이 계산보다 작아지고, 교차 시점은 더 늦어진다.
- PutMetricData·GetMetricData API 요청, 경보, 대시보드, Logs Insights 질의 요금은 넣지 않았다.
- 차원 값 수와 활동 시간은 가정값이다.
