# 009 — EBS 기록 최신성과 보류 검토 비용

[실험 목차](../README.md) · [최종 연구 보고서](../../FINAL-REPORT.md)

**합성 데이터 재현 PASS.** [002의 라벨이 있는 11건](../002-ebs-rule-robustness/cases.json)에 [합성 기록 나이·검토 결과·소요 시간](evidence.json)을 추가하고 기존 규칙 B를 재사용했다. 만료됐거나 작성 시점을 확인할 수 없는 완료 기록은 보류로 보낸다. 검토에서 새 근거가 확보된 사례만 재판정한다. 사후 정답은 평가 집계에만 사용한다.

저장소 루트에서 `py -3 -B experiments/009-ebs-review-cost/evaluate.py`를 실행한다. [결과 원본](result.json)

| 기준 | 초기 오탐 / 미탐 / 보류 | 즉시 재현율 | 보류 검토 후 TP / FP | 가상 보류 검토 시간 |
|---|---:|---:|---:|---:|
| 최신성 기준 없음 | 1 / 2 / 4 | 25% | 2 / 1 | 55분 |
| 최대 90일 | 0 / 1 / 6 | 25% | 3 / 0 | 90분 |
| 최대 30일 | 0 / 1 / 7 | 0% | 3 / 0 | 100분 |

즉시 재현율의 분모는 확정 낭비 4건이다. 보류는 미탐과 별도 집계하고, 사후 상태가 미확정인 두 건은 계속 보류한다. 30일 기준은 이 표본에서 사후 탐지 결과가 90일과 같지만, 초기 보류와 가상 검토 시간이 더 늘었다. 시간은 보류 건별 가상 소요 시간의 합이다. 소요 시간이 입력되지 않은 보류 건에는 건당 10분을 적용했다. 경보 처리 시간과 실제 담당자의 소요 시간은 측정 범위 밖이다. [팀 검토 흐름](../../studies/methods/ebs-waste-review-workflow.md)
