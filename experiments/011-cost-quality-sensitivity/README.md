# 011 — 약정·피크 겹침·전환비에 따른 채택 민감도

[실험 목차](../README.md) · [최종 연구 보고서](../../FINAL-REPORT.md)

**가상 시나리오 재현 PASS.** [EC2 용량 ADR](../../studies/methods/ec2-capacity-decision.md)의 현행 A와 피크 확장 C를 비교한다. 보조 작업 시간, 피크 확장 시간, 두 시간의 가능한 최소·최대 겹침, 일회성 전환비, 품질 판정을 조합했다. 가상 720시간과 ADR의 할인 순서·단가를 그대로 사용했다.

저장소 루트에서 `py -3 -B experiments/011-cost-quality-sensitivity/simulate.py`를 실행한다. [결과 원본](result.json)

135개 조합에서 변경 검토 후보 9건, 유지 81건, 판단 보류 45건이었다. 표본 빈도에는 운영상 확률의 의미가 없다.

- 보조 작업 360시간과 피크 120시간이 전혀 겹치지 않으면 C가 첫 달 $2.40 낮고, 120시간 모두 겹치면 $2.40 높다.
- 보조 작업이 720시간이고 전환비가 $0이면 피크 확장 205시간에서 C가 $0.10 낮지만, 206시간에서는 $0.04 높다.
- 기존 ADR 조건에서 C의 첫 달 차이는 $12.00이다. 전환비가 $12.00이면 동률로 유지하며, 품질을 모르면 비용이 낮아도 보류한다.

서비스 품질·기동·복구의 관측값은 사용하지 않았다. 전환비를 포함한 첫 달 모형이며, 장기 계약 변경이나 실제 월별 청구 절감은 별도 검증 범위다.
