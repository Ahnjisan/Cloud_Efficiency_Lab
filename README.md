# Cloud Efficiency Lab

> 같은 서비스를 운영해도 자원 구성과 실행 환경에 따라 비용과 성능은 어떻게 달라질까?

클라우드에서 서비스를 실행하는 방법뿐 아니라, 운영 비용이 어떻게 발생하고 자원을 얼마나 효율적으로 사용하는지에 관심을 갖고 시작하는 스터디·연구 기록입니다.

AWS를 출발점으로 비용 구조, 자원 사용량, 워크로드 특성을 공부하고, 공식 문서와 논문에서 얻은 내용을 작은 실험으로 확인합니다. 이후 필요한 질문에 따라 컨테이너와 Kubernetes 환경으로 탐구 범위를 넓혀갑니다.

단순히 비용을 줄이는 방법을 모으기보다, 어떤 조건에서 개선이 가능한지, 성능과 안정성에는 어떤 영향이 있는지, 확보한 자료로 어디까지 판단할 수 있는지를 함께 기록합니다.
