# Cloud Efficiency Lab

> 같은 서비스를 운영해도 자원 구성과 실행 환경에 따라 비용과 성능은 어떻게 달라질까?

클라우드 비용과 자원 효율을 공부하고 검증하는 독립적인 개인 스터디·연구 저장소입니다. AWS를 출발점으로 서비스별 과금 구조와 사용량, 낭비가 발생하는 원인과 기존 해결법을 살펴봅니다. 공식 문서·논문·기존 방법을 학습하고 필요한 경우 직접 계산·재현·실험으로 검증합니다. 비용과 함께 성능·안정성, 판단에 필요한 자료와 적용 조건도 기록합니다. 이후 연구 질문에 따라 컨테이너와 Kubernetes 등으로 범위를 넓힐 수 있습니다.

## 학습·연구 방식

개념·자료 학습 → 기존 방법 검토 → 필요한 계산·재현·실험 → 결과와 한계 정리 순서로 진행합니다. 주제에 따라 읽기와 비교, 계산만으로 마무리할 수도 있습니다.

## 기록·운영 원칙

- 출처의 주장, 자신의 해석, 직접 확인한 결과를 구분합니다.
- 실제 관측 자료, 공개 자료, 합성 자료를 구분합니다.
- 예상 비용·절감액과 실제 관측 결과를 구분합니다.
- 판단에 필요한 자료가 부족하면 판단을 보류하고 그 한계를 남깁니다.
- 결과와 적용 조건, 확인하지 못한 한계를 함께 기록합니다.
- Issue·PR 없이 README와 주제별 문서에 진행 상태와 결론을 기록합니다.
- 중요한 결론이 바뀌면 해당 본문을 정정하고 변경 이유를 함께 남깁니다.
